# AirPods Dongle 0.1.68

Reduce USB Game Mode transition processing cost while retaining identical audio
samples, receiver targets and clock policy.

- Sum each fine-search reference energy once and filter four frames together,
  retaining each frame's original tap order and the existing static workspace.
- Keep PCM32 precision, pitch preservation, volume behavior, normal playback,
  radio policy and connection handling unchanged.
- Compare selected lags, history and Q31 output with the former scalar code over
  600 broadband, quiet, silent and fractional-phase entry/exit/reversal jobs.

The PC Pico's RAM-only benchmark measured about 10% less processing time for
fractional-phase transition jobs: mean 3.277/3.306 ms became 2.943/2.964 ms for
the 9/11 ms intervals. The installed flash stayed unchanged through both runs.
These measurements exclude AAC encoding, radio and normal interrupts; they do
not establish acoustic latency or prove uninterrupted playback.

Software checks cover 78 ASan/UBSan native programs, 202 Python checks and the
linked .0076/PCM32 codec and memory gates. Hardware music, both transitions,
pause/resume and volume checks are pending. This candidate must not be described
as a confirmed fix for the reported crackle before those checks pass.
